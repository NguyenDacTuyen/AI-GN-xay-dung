Gộp 2 mẫu thành 1 file & quy trình bóc khối lượng

Dự án AI_Cad_K1 · Gia Nguyễn · Cống – hầm ga – mối nối/gối cống – đào đắp nền đường trong MỘT file Excel.

1 · Gộp được không?

✔ ĐƯỢC  Một file Excel chứa được nhiều sheet (tab). Chỉ cần đưa sheet Dao dap nen duong của mẫu giao thông vào chung file mẫu hầm ga là có 1 file mẫu tổng hợp dùng cho cả 4 loại khối lượng.

Quan trọng: không sửa trên 2 file gốc. Tạo file mới (ví dụ mau-boc-khoi-luong-tong-hop.xlsx) rồi gộp vào đó — gốc vẫn còn để đối chiếu.

2 · Cách gộp — làm thẳng trong Excel (khuyến nghị)

Cách này giữ nguyên 100% định dạng, công thức, màu ô của mẫu. Anh làm 1 lần:

  • B1. Chép mau hamga.xlsx ra 1 bản, đổi tên thành mau-boc-khoi-luong-tong-hop.xlsx. (Chỉ làm trên bản chép, không đụng file gốc.)
  • B2. Mở cả hai: file tổng hợp vừa tạo và mau dao dap giao thong.xlsx.
  • B3. Trong file giao thông, chuột phải vào tab Dao dap nen duong → chọn Move or Copy… (Di chuyển hoặc Sao chép).
  • B4. Hộp thoại hiện ra:
    • Ô To book (Tới sổ): chọn mau-boc-khoi-luong-tong-hop.xlsx.
    • Ô Before sheet (Trước sheet): chọn Tong hop.
    • Tích ☑ Create a copy (Tạo bản sao) — để mẫu giao thông gốc vẫn còn sheet đó.
    • Bấm OK.
  • B5. Ctrl + S lưu lại. Xong — giờ 1 file có đủ các tab.

Hoặc: anh bảo một tiếng, tôi gộp tự động và trả về file mới (giữ định dạng), anh khỏi thao tác tay.

3 · Đưa bản vẽ vào → tính khối lượng theo file mẫu

Anh làm Claude tự chạy Cả hai
  1. Chuẩn bị đầu vàoAnh làm
    • Bản vẽ xuất ra .dxf (trong AutoCAD gõ DXFOUT), đúng bộ layer trắc dọc thoát nước (TP33, TP45, TP46, TP113, TP115, TP118).
    • Điền sheet Thong so và bảng DINH HINH CONG cho đúng công trình (đường kính cống, kích thước hầm ga, gối…).
  2. Bóc thoát nước từ bản vẽ → 3 sheetClaude tự chạy
    • Chạy script đọc DXF, điền tự động: Dao dap cong, Dao dap ho ga, Moi noi-goi cong.
    • Khối lượng để dưới dạng công thức; chỗ thiếu ghi [Chờ bổ sung], không bịa số.
  3. Xuất CSV đào đắp nền đường từ ADSdesignAnh làm
    • Phần giao thông (san nền, đào đắp nền đường) chưa đọc tự động từ bản vẽ được — dải bảng khối lượng trong DXF không tin cậy.
    • Anh xuất bảng khối lượng ra .csv từ phần mềm ADSdesign (như lần này).
  4. Đổ CSV vào sheet Dao dap nen duongClaude tự chạy
    Chạy công cụ đổ CSV → điền sheet giao thông, số cột tự co giãn theo số công tác trong CSV, định dạng & màu theo mẫu, vừa 1 trang in ngang.
  5. Kiểm tra & tổng hợpCả hai
    • Sheet Tong hop tự cộng khối lượng các sheet (giếng thu, cống D400/D600, đào hào, thép, mối nối…).
    • Claude: agent kiểm tra độc lập rà số học, đối chiếu bản vẽ.
    • Anh: duyệt các ô vàng (thông số thi công), quyết mã tương tự.
  6. Xuất file kết quảClaude tự chạy
    Ghi ra file kết quả riêng trong ket-qua/ (không ghi đè file mẫu). Đây là bảng khối lượng để anh nhập vào F1 áp đơn giá, lập dự toán.

Lưu ý quan trọng

  • 1 file mẫu – nhiều sheet là đúng cách làm. Mỗi loại khối lượng 1 tab, sheet Tong hop cộng lại. Dễ quản lý, dễ đối chiếu.
  • "Đưa bản vẽ là ra hết" đúng cho thoát nước (cống, hầm ga, mối nối/gối) — nếu DXF đúng chuẩn layer. Giao thông cần thêm 1 bước: xuất CSV từ ADSdesign (bước 3).
  • Ra khối lượng, chưa phải ra dự toán. Dự toán đầy đủ vẫn cần áp đơn giá trên F1 (ĐM TT 38/2026, đơn giá HCM QĐ 4570/2026) rồi mới tổng hợp.
  • Nguyên tắc xuyên suốt: không ghi đè file mẫu/gốc, không bịa số, mọi khối lượng có công thức để kiểm.
